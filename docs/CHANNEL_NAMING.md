# Название канала — GLIX

Дата решения владельца: 2026-11-25.

- Отображаемое имя: **GLIX** (латиница, uppercase).
- Произношение по-русски: «Гликс».
- Позиционирование: яркие юмористические игровые Motion Comics для аудитории 18–34.
- Имя выбрано для канала, а не как утверждение об исключительных правах на товарный знак. KEXO и предыдущие варианты отложены.
- Предпочтительный handle: `@glix`; резервные кандидаты при недоступности: `@glixcomics`, `@glixplays`. Доступность не проверена, резервные варианты не утверждены. Регистрация и создание аккаунтов не выполнялись.
- Рабочий слоган: «Игровая логика без логики» (не утверждён, не обязательная часть логотипа).

Визуальное оформление — [brand guide](BRAND_VISUAL_GUIDE.md). Название не блокирует производство чистого пилота; логотип, аватар и баннер требуют отдельного художественного review. Не менять имя репозитория или идентификаторы движка.
