# ADR 0001: file-first foundation локальной видеостудии

- Статус: accepted for Stage 0
- Дата: 2026-11-24

## Контекст

Проекту нужен управляемый производственный pipeline, но пока нет основания для сервера, БД, очередей или отдельного UI. Codex должен опираться на проверяемые файлы и локальные инструменты.

## Решение

1. Хранить контракты стадий, конфигурацию каналов, идеи, сценарии, storyboard, manifests и QA records как Markdown/JSON/YAML/медиа-файлы.
2. Использовать immutable IDs, schemaVersion, source SHA, timestamps, paths и SHA-256 для связи артефактов.
3. Оркестрацию выполнять локальными CLI-командами; форматы должны оставаться пригодными для будущего UI без его ранней реализации.
4. Держать G0–G8 независимыми gates: следующий этап читает только принятые outputs предыдущего.
5. Remotion считать целевым основным движком, но dependency setup и render usage блокировать до проверки актуальной лицензии и Stage 1 решения.

## Рассмотренные варианты

- Сервер + БД + очередь: отклонено как преждевременное усложнение.
- Один неструктурированный каталог: отклонено из-за слабой трассируемости и невозможности строгих gates.
- File-first + JSON Schema: выбрано как минимальное, переносимое и проверяемое решение.

## Последствия

Stage 0 определяет контракты, но не реализует production engine. Параллельная запись в один JSON-файл не поддерживается; при росте объёма сначала вводятся атомарные CLI-операции и только затем оценивается БД.
